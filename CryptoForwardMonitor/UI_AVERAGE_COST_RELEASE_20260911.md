# 持倉成本均價與浮動盈虧 — 2026-09-11

## 使用

「資產總覽」中 V3.10、V3.1 的 BTC／ETH 市值列下方，顯示成本均價與浮動盈虧百分比。正值綠色、負值紅色；空倉或成本無法核對時不顯示虛構的 0%／零成本。

成本均價採移動加權平均：買入以實際 cash_change_usd 支出加入成本（含買入手續費及滑價）；賣出按數量比例移除成本，不以賣出所得降低剩餘持倉均價。

浮動盈虧 % = （目前持倉估值 ÷ 剩餘持倉成本 − 1）× 100。

這不是帳戶累積報酬率，不含未來賣出費用。行情無法取得時沿用介面既有估值口徑，估值來源仍標示在卡片下方。

## 期初口徑

前瞻測試從 USD 20,000 正規化開始，但持倉來自歷史模型，並非前瞻起點全部重新買入。成本由完整歷史成交計算，再將成本及持倉數量同比例縮放，接續前瞻成交。均價不是起點市價，也不能據此把前瞻測試開始前的盈虧視為本次測試報酬。
